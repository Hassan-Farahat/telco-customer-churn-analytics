# 📊 Telco Customer Churn Analytics

An interactive Streamlit dashboard analyzing customer churn metrics across contract types, internet services, and payment methods.

🔗 **Live Demo:** [Telco Churn Dashboard](https://hassan-farahat-telco-customer-churn-analytics-app-7weiwz.streamlit.app/)

## Features
- Real-time filtering by Contract, Internet Service, and Payment Method.
- Key KPIs: Total Customers, Churned Customers, and Churn Rate.
- Annotated seaborn visual metrics.
- Expandable raw dataset viewer.
